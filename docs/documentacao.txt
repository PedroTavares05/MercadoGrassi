Este manual completo parte do computador limpo (sem pasta, sem banco configurado, sem pacotes) até o sistema **MercadoGrassi** rodando no navegador. Se você abrir um VS Code vazio agora e seguir cada comando na ordem, o projeto inteiro nasce idêntico ao seu repositório.

## Fase 1: Preparação do Ambiente e VS Code

Antes de criar qualquer arquivo, garanta que as ferramentas base e as extensões do VS Code estejam prontas.

### 1. Softwares Obrigatórios na Máquina

* **Node.js (v18 ou v20 LTS)**: Inclui o `node` (motor que roda o JavaScript no servidor) e o `npm` (gerenciador de pacotes). Teste no terminal com `node -v` e `npm -v`.
* **MySQL Server (8.0+)**: O banco de dados relacional onde ficará o schema `db_mercado_grassi`.
* **Git Bash**: Terminal recomendado no Windows para rodar os comandos `mkdir`, `touch` e `npm` sem erros de permissão.

### 2. Extensões do VS Code para este Projeto

Instale estas extensões na aba **Extensions (`Ctrl + Shift + X`)** do VS Code para não programar no escuro:

* **EJS Language Support** (*DigitalBrainstem*): Ativa syntax highlighting e autocomplete das tags `<% %>` e `<%= %>` nos arquivos `.ejs` dentro de `client/views/`. Sem ela, o VS Code trata o EJS como texto puro ou reclama de erro no HTML.


* **Prettier - Code formatter**: Formata automaticamente seus arquivos JavaScript (`.js`) em `server/` e HTML/EJS ao salvar.


* **vscode-icons**: Diferencia visualmente as pastas `client`, `server`, `routes`, `controller`, `models`, `config` e `data` na barra lateral.


* **DotENV** (*mikestead*): Colore a sintaxe das variáveis chave-valor dentro do arquivo `server/.env`.


* **MySQL** (*Weijan Chen* ou *cweijan*): Permite conectar no MySQL direto de dentro do VS Code e rodar o script `data/MercadoGrassi.sql` sem precisar abrir o Workbench.



## Fase 2: Criação da Estrutura de Pastas do Zero

Abra o **Git Bash** (ou o terminal integrado do VS Code com `Ctrl + '`), navegue até a área de trabalho ou pasta de projetos e rode este bloco de comandos. Ele cria a pasta raiz e todas as subpastas do **MercadoGrassi** de uma vez:

## Fase 3: Inicialização do NPM e Instalação dos Pacotes

Toda a aplicação Node.js roda de dentro da pasta **`server/`**. Você nunca roda `npm install` na raiz `MercadoGrassi/`, mas sim dentro de `MercadoGrassi/server/`.

### 1. Inicializar o `package.json`

No terminal do VS Code, entre na pasta `server` e inicie o projeto Node:

```bash
cd server
npm init -y

```

(Isso cria o arquivo `server/package.json` padrão).

### 2. Instalar as Dependências do Projeto

Rode o comando abaixo (ainda dentro de `server/`) para baixar todas as bibliotecas necessárias e gerar a pasta `node_modules` e o `package-lock.json`:

```bash
npm install dotenv ejs express express-session mysql2 nodemon

```

**O que cada comando/pacote instalado faz no seu projeto:**

* **`express`**: É o coração do servidor (`server.js`). Escuta a porta HTTP, recebe requisições GET/POST, lê dados de formulários HTML (`express.urlencoded`) e divide o sistema em rotas (`express.Router()`).


* **`ejs`**: É o motor de visualização. O Express usa o EJS para ler os arquivos `.ejs` da pasta `../client/views`, trocar as tags `<%= %>` pelos dados do MySQL e devolver HTML puro para o navegador.


* **`mysql2`**: É o driver que conecta o Node.js ao MySQL (`server/config/db.js`). Usamos o modo `mysql2/promise` para poder usar `async/await` nos Models e `?` nas queries (evitando SQL Injection).


* **`express-session`**: Cria e gerencia a sessão do usuário logado na memória do servidor e grava o cookie de sessão no navegador quando ele faz login em `Login.ejs`.


* **`dotenv`**: Lê o arquivo `server/.env` e carrega os valores dentro do objeto global `process.env` do Node.


* **`nodemon`**: Monitora seus arquivos `.js` e `.ejs`. Toda vez que você aperta `Ctrl + S`, ele reinicia o servidor sozinho no terminal.



### 3. Configurar o Script de Execução no `server/package.json`

Abra o arquivo `server/package.json` gerado e deixe-o exatamente assim para que o comando `npm start` já rode com o `nodemon`:

```json
{
  "name": "server",
  "version": "1.0.0",
  "description": "Backend MVC Mercado Grassi",
  "main": "server.js",
  "scripts": {
    "start": "nodemon server.js",
    "dev": "nodemon server.js"
  },
  "dependencies": {
    "dotenv": "^16.4.5",
    "ejs": "^3.1.10",
    "express": "^4.19.2",
    "express-session": "^1.18.0",
    "mysql2": "^3.11.0",
    "nodemon": "^3.1.4"
  }
}

```

## Fase 6: Criação dos Models (`server/models/`)

Os Models são os únicos arquivos que conversam com o banco de dados (`db.execute`).

1. Crie **`server/models/produtosModels.js`**:



```javascript
const db = require('../config/db');

const ProdutosModel = {
    listarTodos: async () => {
        const [rows] = await db.execute('SELECT * FROM tb_produtos ORDER BY id DESC');
        return rows;
    },

    buscarPorId: async (id) => {
        const [rows] = await db.execute('SELECT * FROM tb_produtos WHERE id = ?', [id]);
        return rows[0];
    },

    criar: async ({ nome, categoria, preco, quantidade }) => {
        const sql = 'INSERT INTO tb_produtos (nome, categoria, preco, quantidade) VALUES (?, ?, ?, ?)';
        const [result] = await db.execute(sql, [nome, categoria, preco, quantidade]);
        return result;
    },

    atualizar: async (id, { nome, categoria, preco, quantidade }) => {
        const sql = 'UPDATE tb_produtos SET nome = ?, categoria = ?, preco = ?, quantidade = ? WHERE id = ?';
        const [result] = await db.execute(sql, [nome, categoria, preco, quantidade, id]);
        return result;
    }
};

module.exports = ProdutosModel;

```

2. Crie **`server/models/usuarioModels.js`**:



```javascript
const db = require('../config/db');

const UsuarioModel = {
    listarTodos: async () => {
        const [rows] = await db.execute('SELECT id, nome, email, cargo FROM tb_usuarios');
        return rows;
    },

    criar: async ({ nome, email, senha, cargo }) => {
        const sql = 'INSERT INTO tb_usuarios (nome, email, senha, cargo) VALUES (?, ?, ?, ?)';
        const [result] = await db.execute(sql, [nome, email, senha, cargo || 'Operador']);
        return result;
    },

    autenticar: async (email, senha) => {
        const sql = 'SELECT * FROM tb_usuarios WHERE email = ? AND senha = ?';
        const [rows] = await db.execute(sql, [email, senha]);
        return rows[0];
    }
};

module.exports = UsuarioModel;

```

## Fase 7: Criação dos Controllers (`server/controller/`)

Os Controllers fazem o meio de campo: recebem `req` da rota, chamam o Model e respondem com `res.render()` ou `res.redirect()`.

1. Crie **`server/controller/produtosController.js`**:



```javascript
const ProdutosModel = require('../models/produtosModels');

const produtosController = {
    listar: async (req, res) => {
        try {
            const produtos = await ProdutosModel.listarTodos();
            res.render('produtos/listar', { produtos });
        } catch (error) {
            res.render('produtos/error', { mensagem: 'Erro ao listar produtos: ' + error.message });
        }
    },

    formCadastrar: (req, res) => {
        res.render('produtos/cadastrar');
    },

    criar: async (req, res) => {
        try {
            const { nome, categoria, preco, quantidade } = req.body;
            await ProdutosModel.criar({
                nome: nome ?? '',
                categoria: categoria ?? '',
                preco: preco ?? 0,
                quantidade: quantidade ?? 0
            });
            res.redirect('/produtos/listar');
        } catch (error) {
            res.render('produtos/error', { mensagem: 'Erro ao cadastrar produto: ' + error.message });
        }
    },

    formEditar: async (req, res) => {
        try {
            const produto = await ProdutosModel.buscarPorId(req.params.id);
            res.render('produtos/editar', { produto });
        } catch (error) {
            res.render('produtos/error', { mensagem: 'Erro ao carregar edição: ' + error.message });
        }
    },

    atualizar: async (req, res) => {
        try {
            const { nome, categoria, preco, quantidade } = req.body;
            await ProdutosModel.atualizar(req.params.id, {
                nome: nome ?? '',
                categoria: categoria ?? '',
                preco: preco ?? 0,
                quantidade: quantidade ?? 0
            });
            res.redirect('/produtos/listar');
        } catch (error) {
            res.render('produtos/error', { mensagem: 'Erro ao atualizar produto: ' + error.message });
        }
    }
};

module.exports = produtosController;

```

2. Crie **`server/controller/usuarioController.js`**:



```javascript
const UsuarioModel = require('../models/usuarioModels');

const usuarioController = {
    index: (req, res) => {
        res.render('Usuarios/index');
    },

    formLogin: (req, res) => {
        res.render('Usuarios/Login', { erro: null });
    },

    login: async (req, res) => {
        try {
            const { email, senha } = req.body;
            const usuario = await UsuarioModel.autenticar(email ?? '', senha ?? '');
            if (!usuario) {
                return res.render('Usuarios/Login', { erro: 'E-mail ou senha inválidos.' });
            }
            req.session.usuario = { id: usuario.id, nome: usuario.nome, cargo: usuario.cargo };
            res.redirect('/produtos/listar');
        } catch (error) {
            res.render('Usuarios/Login', { erro: 'Falha ao autenticar: ' + error.message });
        }
    },

    formCadastro: (req, res) => {
        res.render('Usuarios/cadastrauser');
    },

    cadastrar: async (req, res) => {
        try {
            const { nome, email, senha, cargo } = req.body;
            await UsuarioModel.criar({
                nome: nome ?? '',
                email: email ?? '',
                senha: senha ?? '',
                cargo: cargo ?? 'Operador'
            });
            res.redirect('/usuarios/listar');
        } catch (error) {
            res.status(500).send('Erro ao cadastrar usuário: ' + error.message);
        }
    },

    listar: async (req, res) => {
        try {
            const usuarios = await UsuarioModel.listarTodos();
            res.render('Usuarios/ListarUser', { usuarios });
        } catch (error) {
            res.status(500).send('Erro ao listar usuários: ' + error.message);
        }
    }
};

module.exports = usuarioController;

```

3. Crie o arquivo principal **`server/server.js`**:



```javascript
const express = require('express');
const session = require('express-session');
const path = require('path');
require('dotenv').config();

const produtosRoutes = require('./routes/produtosRoutes');
const usuarioRoutes = require('./routes/usuarioRoutes');

const app = express();
const PORT = process.env.PORT || 3000;

// Configura o EJS e aponta para a pasta client/views fora de server/
app.set('view engine', 'ejs');
app.set('views', path.join(__dirname, '../client/views'));

// Permite ler o req.body enviado pelos formulários HTML (<form method="POST">)
app.use(express.urlencoded({ extended: true }));
app.use(express.json());

// Ativa o controle de sessão
app.use(session({
    secret: process.env.SESSION_SECRET || 'chave_padrao_grassi',
    resave: false,
    saveUninitialized: false
}));

// Conecta os prefixos de rota aos arquivos da pasta routes/
app.use('/produtos', produtosRoutes);
app.use('/usuarios', usuarioRoutes);

// Rota principal redireciona para a tela de login
app.get('/', (req, res) => {
    res.redirect('/usuarios/login');
});

app.listen(PORT, () => {
    console.log(`Servidor MercadoGrassi rodando em: http://localhost:${PORT}`);
});

```
